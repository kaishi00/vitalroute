VitalRoute

Your health data, routed to your own server.

GitHub repository Privacy Policy Support

What it does

VitalRoute is a native iOS app that sends the Apple Health data you explicitly select to an HTTPS endpoint you control. You choose which metrics leave the device, you choose where they go, and the included reference receiver stores them on your own hardware.

Principles

  • Nothing is collected by the developer. There is no developer cloud.
  • Every metric is off by default. You opt in per metric.
  • Read-only access to Apple Health. VitalRoute never writes to Health.
  • No analytics, no advertising, no accounts, no third-party SDKs.
  • Your endpoint and its API key are stored in the device Keychain.

Getting started

Deploy the reference receiver, point VitalRoute at your HTTPS endpoint, select the metrics you want, and sync. Full setup instructions are in the repository README and the in-app setup guide.
